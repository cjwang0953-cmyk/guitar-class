3. 音階與 4. 和弦定義

  • 3. 音階（Scales）：
    將音符按特定音程排列的集合。例如大調音階為「全-全-半-全-全-全-半」（即音程：M2-M2-m2-M2-M2-M2-m2）。
  • 4. 和弦定義（Chord Definitions）：
    三個或以上的音，按特定音程疊加（通常為三度疊置）：
    • 大三和弦 (Major Triad)： 根音 + 大三度 (M3) + 完全五度 (P5) [例如 C - E - G]
    • 小三和弦 (Minor Triad)： 根音 + 小三度 (m3) + 完全五度 (P5) [例如 C - E♭ - G]

5. 基本和弦架構 - 三和弦 (Triad)

由三個相距三度的音所組成（主音 + 三音 + 五音），可分為四種基本型態：

類別音程組成 (由下而上)組成音和弦記號
1) 大三和弦M3, m31, 3, 5無 , maj , M 或 Δ
2) 小三和弦m3, M31, ♭3, 5m , min 或 -
3) 減三和弦m3, m31, ♭3, ♭5dim 或 o
4) 增三和弦M3, M31, 3, ♯5aug 或 +

結構與範例說明：

  • 大三和弦 (Major Triad)： Root + M3 + m3 (P5) ➔ 例：C (1, 3, 5) / D (2, ♯4, 6)
  • 小三和弦 (minor Triad)： Root + m3 + M3 (P5) ➔ 例：Am (6, 1, 3) / Em (3, 5, 7)
  • 增三和弦 (Augmented Triad)： Root + M3 + M3 (A5) ➔ 例：Caug (1, 3, ♯5) / A+ (6, ♯1, 4) ※ "+" 代表 5 音升半音
  • 減三和弦 (Diminished Triad)： Root + m3 + m3 (D5) ➔ 例：Bdim (7, 2, 4)

5. 基本和弦架構 - 七和弦 (7th Chord)

以三和弦為基礎，再疊加一個由根音往上的「7度音」，共由四個音組成：

類別音程組成組成音和弦記號
1) 大七和弦M3, m3, M31, 3, 5, 7maj7 , M7 或 Δ7
2) 小七和弦m3, M3, m31, ♭3, 5, ♭7m7 , min7 或 -7
3) 屬七和弦M3, m3, m31, 3, 5, ♭77
4) 半減七和弦m3, m3, M31, ♭3, ♭5, ♭7m7(♭5) , m7-5 或 ϕ
5) 減七和弦m3, m3, m31, ♭3, ♭5, ♭♭7dim7 , o7

結構範例與推導：

  • 大七和弦 (Major Seven)： [大三和弦 + 大七度] ➔ 例：Cmaj7 (1, 3, 5, 7) / Gmaj7 (5, 7, 2, ♯4)
    ※ 口訣：除了 maj7 是大7度外，其餘常見七和弦皆含 ♭7！
  • 小七和弦 (minor Seven)： [小三和弦 + 小七度] ➔ 例：Em7 (3, 5, 7, 2) / Cm7 (1, ♭3, 5, ♭7)
  • 屬七和弦 (Dominant Seven)： [大三和弦 + 小七度] ➔ 例：G7 (5, 7, 2, 4) / C7 (1, 3, 5, ♭7)

實作與推算：C 大調指板

  • C 自然大調音階： C — D — E — F — G — A — B — C
  • 音級對照： 1級(主) — 2級(上主) — 3級(中) — 4級(下屬) — 5級(屬) — 6級(下中) — 7級(導)
  • 關鍵記憶： E - F (3-4級) 與 B - C (7-1級) 為小二度 (半音/相鄰1格)，其餘皆為大二度 (全音/相隔2格)。

課後實作練習：

1. 在吉他第 6 弦與第 5 弦上，依序找出 C(1) - D(2) - E(3) - F(4) - G(5) - A(6) - B(7) 的位置。

2. 體會 7 級音 (B) 彈完後，手指想彈回 1 級音 (C) 的「導音解決感」。

3. 壓出 1級(C) + 3級(E) + 5級(G)，驗證大三度的明亮聽感。
