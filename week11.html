第 11 週課程重點與實作應用

  • 三和弦 (Triad) 的基本結構： 三和弦由根音 (R)、三度音 (3rd) 與五度音 (5th) 組成。透過改變三度與五度音程，可構建 Major (1-3-5)、Minor (1-b3-5)、Diminished (1-b3-b5) 與 Augmented (1-3-#5) 四種基本三和弦。
  • 三音組 (String Sets) 橫向平移： 將吉他 6 根弦拆分為 4 組三音組：
    • Set 1: 1-2-3 弦（高音聲部，最適合旋律彈奏與伴奏 Fill-in）
    • Set 2: 2-3-4 弦
    • Set 3: 3-4-5 弦
    • Set 4: 4-5-6 弦（低音聲部，構造與 Set 3 完全一致）
  • 三種轉位指型 (Inversions)： 在同一組 String Set 上，沿著琴頸橫向移動，會依序出現 **本位 (Root Position)**、**第一轉位 (1st Inversion)** 與 **第二轉位 (2nd Inversion)**，實現全指板無縫銜接的橫向巡航。
